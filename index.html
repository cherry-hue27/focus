專案主題： Focus Synth - 賽博專注時計

一、網站連結資訊
  • GitHub Pages 實際公開網站： https://cherry-hue27.github.io/focus/
  • GitHub 專案原始碼儲存庫： https://github.com/cherry-hue27/focus
二、步驟一：規格書說明 (Specification)
  • 動態專注計時器 (Pomodoro Timer)： 支援 25 分鐘專注與 5 分鐘休息切換，提供開始/暫停/重置功能，外圍搭配 SVG 環形動態扣減邊框與霓虹視覺。
  • Web Audio 白噪音體驗： 點擊按鈕可隨時開關背景白噪音，採用原生 Web Audio API 動態合成低頻聲音，無須外部 MP3 檔案。
  • 互動任務清單 (Todo List)： 使用者可動態新增任務目標，點擊任務項目可標記劃線完成，點擊「✕」可移除任務。
三、步驟二：Vibe Coding 實作與 AI 討論反覆調整過程
  • 第一輪 Prompt (基礎架構)： 向 AI 說明希望打造 Cyberpunk 霓虹風格網頁，並要求將 HTML、CSS、JS 打包在單一 index.html 檔案內。
  • 第二輪 Prompt (動態動畫加強)： 要求 AI 將專注計時器外圍加上 SVG 圓圈進度條，並利用 CSS `stroke-dashoffset` 達到時間流逝扣減效果。
  • 第三輪 Prompt (音效與架構優化)： 請 AI 避開外部音效檔資源，直接用 JS Web Audio API 合成音效，完美做到零外部套件依賴。
